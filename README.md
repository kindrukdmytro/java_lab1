## Опис проєкту

У роботі показано систему обробки станів замовлення з використанням принципів DOP.
Для представлення даних використав sealed interface та records. Бізнес-логіка у класі OrderProcessor.
Чотири стани замовлення:

1. Pending - очікування обробки.
2. Paid - замовлення оплачено.
3. Shipped - замовлення відправлено.
4. Cancelled - замовлення скасовано.

Для обробки станів використав Switch Expressions, Pattern Matching та Text Blocks.
